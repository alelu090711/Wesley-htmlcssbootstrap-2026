Minha primeira página usando HTML com Bootstrap

Bootstrap é um framework de desenvolvimento web que fornece componentes e estilos prontos em HTML, CSS e JavaScript, facilitando a criação de sites bonitos, responsivos e adaptados para celular, tablet e computador.

Download

Download serve para você ter os arquivos do Bootstrap no seu próprio projeto.

A ideia principal: você baixa o Bootstrap → coloca os arquivos dentro do projeto → conecta o CSS e o JS no HTML → pode começar a usar as classes do Bootstrap.
